返金ポリシー

最終更新：2026-08-19

API Key Case Pro は、購入から14日以内であれば、原則として理由を問わず返金を申請できます。

返金処理は Merchant of Record である Lemon Squeezy が行います。本ポリシーは、法令上認められる利用者の権利を制限しません。

1. 対象となる申請

  • API Key Case Pro の購入完了日時から14日以内に申請されていること
  • 購入者本人または正当に権限を有する者からの申請であること
  • Lemon Squeezy が注文を特定し、返金処理できること

動作しなかった、期待と違った、誤って購入したなど、理由の説明は必須ではありません。可能であれば、製品改善のため任意でフィードバックをお寄せください。

2. 申請方法

  1. 原則として、Lemon Squeezy の注文完了メールまたは注文ページから、当該注文に関するサポート・返金の案内へ進みます。
  2. Lemon Squeezy の窓口を利用できない場合は、dev@melavern.com へ個別に連絡してください。注文を特定するための情報は、この二つの非公開経路だけに送ります。

公開の GitHub Issues に、注文番号、購入キー、メールアドレス、カード情報その他の購入者情報を投稿しないでください。カード番号、セキュリティコードその他のカード情報は、メールにも送らないでください。 操作方法の一般的な案内だけが必要な場合は、個人情報や注文情報を含めずに GitHub Issues で尋ねてください。個別の購入・返金手続きは Lemon Squeezy の注文窓口または dev@melavern.com という非公開経路を利用してください。

3. 対象外となる場合

次の場合は、法令上返金が必要な場合を除き、本ポリシーによる返金をお断りすることがあります。

  • 購入から14日を経過した申請
  • 虚偽、詐欺、不正な決済、返金制度の反復的な濫用または操作的行為が認められる場合
  • 購入者または注文を合理的に確認できない場合
  • 本ポリシーと無関係な外部サービス料金、通信料金、為替手数料、税の還付その他の請求

4. 返金額と処理期間

承認された返金は、原則として当該注文で実際に支払った商品代金を対象とします。税、為替換算、返金先、反映時期および決済手数料の取扱いは、適用法令、Lemon Squeezy および決済手段の条件に従います。

返金承認後、利用明細へ反映されるまでの期間は、カード会社、銀行その他の決済事業者により異なります。

5. 返金後の Pro ライセンス

返金、注文取消しまたはチャージバックが成立した時点で、Pro の利用権は終了します。以後、その購入キーによる新しいライセンス交換はできません。

API Key Case の Pro 判定は有効化後オフラインであるため、発行済みライセンスを開発者が遠隔で削除または失効させることはできません。返金を受けた利用者は、Pro の利用を停止し、各端末で次を実行してください。

6. 交換・再提供

デジタル利用権のため、物品としての返品・交換はありません。購入キーが届かない、重複請求、技術的な理由で有効化できないなど、提供上の問題がある場合は、返金に加えて再送または問題解決が可能な場合があります。Lemon Squeezy の注文窓口または dev@melavern.com からご連絡ください。

7. チャージバック

不正利用を除き、カード会社へのチャージバックを申し立てる前に、まず Lemon Squeezy の注文窓口へご連絡ください。正当な購入に対する不当なチャージバックは、Lemon Squeezy の Buyer Terms および利用規約に従って取り扱われます。

8. お問い合わせ

取引固有の返金連絡は Lemon Squeezy の注文メールまたは注文ページ、または dev@melavern.com へお願いします。一般的な製品情報と公開窓口は、特定商取引法に基づく表記をご確認ください。
