OSごとの補足

Windows — 人が承認したことを確かめるために

通常対応はWindows 11＋Windows Helloです。本番への配置やAPIキーの削除などは、AIや別のソフトが代わりに承認できないよう、Windows Hello（顔・指紋・PIN）で本人確認を行います。

Windows 10やHello未設定でも確認・保存などの無料機能は条件に応じて使えますが、重要な操作と配置の対象環境ではありません。

macOS — 実際のMacでの確認を進めています

Keychainへの保存は確認済みですが、専用画面での入力・承認から配置までの流れと、Intel Macでの確認はまだ完了していません。Windows Helloに相当する本人確認も未実装のため、Windowsと同等の保護は確認できていません。

macOSではProの配置機能を実機検証中です。購入はできますが、現時点では正常な動作を保証していません。

Linux / Ubuntu — 保管庫の利用条件が環境で異なります

保存はご自身のターミナルから行います。再ログイン・再起動後も保存が残るかは、すべての構成では確認できていません。専用画面での入力・承認の仕組みが未提供のため、AIに任せる形での配置も現在提供していません。

macOS協力検証について

macOS正式対応に向けて、実際のMacでの確認に協力していただける方を少人数募集しています。

協力者向け価格は980円です。通常Proは2,980円買い切りで、980円は対象の協力者への個別提供条件です。通常サポートではありません。

応募 → Mac環境の確認 → 対象の方へ個別案内 → 実機検証の順で進めます。初回は30〜60分程度、不具合修正後に必要な場合のみ10〜20分程度の再確認をお願いします。

Apple Silicon / Intelの両方から応募できます。環境や現在の検証状況に応じて、お願いする内容が異なる場合があります。応募後に、Macの機種・CPU、macOS、利用するAIエージェント、Node.jsの導入方法、本人確認手段、試したい配置先を確認します。

実際のAPIキー、.env、購入キー（ライセンスキー）、アクセストークン、未加工ログは送らないでください。

検証記録

このページには、利用判断に必要な内容だけを載せています。確認結果の時系列は検証記録、公開条件はリリース確認内容で公開しています。

APIキーの値はAIに返さず、OS標準の保管庫へ保存します。守る範囲と限界はSECURITY.mdをご覧ください。完全な安全を保証するものではなく、事故の確率を下げるための仕組みです。

技術的な検証情報を見る
  • Windows: Windows 11 Home 25H2 / build 26200.9168 x64、Node.js 24.15で、入力、中断からの再開、Windows Helloでの承認・拒否、削除、配置先の信頼解除、3社への配置を実機確認。
  • macOS: 2026-09-12にGitHub Actionsの全9ジョブが成功し、ログインKeychainを使った実Keychain E2Eも成功。対象commit 255ab6e、Actions run 34670958401。Keychain E2Eのrunは 34670069746。
  • Linux: Ubuntu 24.04 x64 / Node.js 22.22.2で、D-Bus / Secret Serviceによる保管庫テストを確認。

macOSは、専用画面での入力・承認・配置、別のソフトによる確認画面の自動操作への耐性、Intel Macでの動作が未検証です。

2026-09-08時点の「macOS CI未実行」は当時の観測として記録に残し、2026-09-12に成立したCI・実Keychainの結果とは区別しています。ここにある番号は、公開前の検証を後から追跡するための参照情報です。現在の対応可否は、このページ上部の対応状況を確認してください。
